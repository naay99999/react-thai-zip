`ThaiAddressCascadeSelect` is for forms where people choose an address in the order province → district → sub-district.

<ComponentPreview name="cascade-select-en" lang="en" size="lg" />

## Installation

<ComponentInstall name="cascade-select" lang="en" />

## Usage

```tsx
import { ThaiAddressCascadeSelect } from '@/components/thai-address-cascade-select'
```

```tsx
<ThaiAddressCascadeSelect onValueChange={(address) => console.log(address)} />
```

`onValueChange` receives `ResolvedThaiAddress | null` once all three levels have been chosen.

### Changing a parent choice

After a complete selection, changing the province or district emits `onValueChange(null)` and clears downstream selections that no longer match. The person then chooses the remaining address levels again.

### Custom text

Use `texts` to override labels and placeholders, for example to match Bangkok's khet/khwaeng wording. Keys you don't pass keep the `locale` defaults.

<ComponentPreview name="cascade-select-texts-en" lang="en" size="lg" />

### Form

Pass `name` to submit the selection with a regular form: the component renders four hidden inputs (`address-subdistrict`, `address-district`, `address-province`, `address-zipcode`). `required` blocks submission until all three levels are chosen.

<ComponentPreview name="form-cascade-select-en" lang="en" size="lg" />

The cascade does not emit a resolved value until all three levels are selected. While a province or district is only partly chosen, the component keeps that state itself: `value={null}` clears a complete selection but keeps a partial one. If a form reset must also clear a partial selection, remount it with a key:

```tsx
<ThaiAddressCascadeSelect key={resetVersion} name="address" value={address} onValueChange={setAddress} />
```

## API Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `ResolvedThaiAddress \| null` | — | Controlled value; pass `null` to clear it. |
| `defaultValue` | `ResolvedThaiAddress \| null` | — | Uncontrolled seed value; pre-selects the complete address chain. |
| `onValueChange` | `(address: ResolvedThaiAddress \| null) => void` | — | Called when an address is completed or cleared. |
| `name` | `string` | — | Renders four hidden inputs: `<name>-subdistrict`, `-district`, `-province`, `-zipcode`. |
| `locale` | `'th' \| 'en'` | `'th'` | Label and option locale. |
| `texts` | `Partial<ThaiAddressCascadeSelectTexts>` | — | Overrides the `*Label`/`*Placeholder` text of each level plus `loadingText`, `errorText`, `retryLabel`. |
| `indexLoad` | `'mount' \| 'visible'` | `'mount'` | Load the address data on mount, or only once the field scrolls into view. |
| `disabled` | `boolean` | `false` | Disables all selects. |
| `required` | `boolean` | — | Marks all three selects as required. |
| `aria-invalid` | `React.AriaAttributes['aria-invalid']` | — | Marks all three triggers invalid. |
| `onBlur` | `React.FocusEventHandler<HTMLButtonElement>` | — | Runs when the province trigger loses focus. |
| `onError` | `(error: Error) => void` | — | Runs if the address index cannot load. |
| `className` | `string` | — | Root grid wrapper. |
| `labelClassName` | `string` | — | Every field label. |
| `triggerClassName` | `string` | — | Select triggers and the postal-code input. |
| `popupClassName` | `string` | — | Option popups. |
| `itemClassName` | `string` | — | Each option item. |
| `ref` | `React.Ref<HTMLButtonElement>` | — | Forwarded to the province trigger, the cascade's primary control. |

Both `ref` and `onBlur` target the province trigger, not the district or sub-district trigger.
