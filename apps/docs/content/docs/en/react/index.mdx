react-thaizip is a CLI, not a component library you install as a dependency. It copies component source into your project, the same way [shadcn/ui](https://ui.shadcn.com/) does, so the files are yours to change.

## Prerequisites

Node.js 18 or later, and a React or Next.js project with Tailwind CSS v3 or v4 already installed. `init` detects Tailwind; it does not install it.

## Set up

```npm
npx react-thaizip init
```

`init` detects the project layout, package manager, TypeScript, Tailwind, and shadcn/ui, adds design tokens to your global stylesheet, installs `thaizip`, and writes `thaizip.config.json`. With a shadcn/ui `components.json`, components are composed from your own primitives (Base UI, Radix, or React Aria); otherwise you get the vanilla Base UI style. With Tailwind v3 it also prints a `theme.extend` snippet to add by hand.

## Add a component

```npm
npx react-thaizip add autocomplete
```

```text
components/
  thai-address-autocomplete.tsx
hooks/
  use-thai-address-index.ts
lib/
  utils.ts
```

`add` also installs missing dependencies and prints the import path. Use that path: examples in these docs use the `@/components/...` alias.

```tsx
import { ThaiAddressAutocomplete } from '@/components/thai-address-autocomplete'

export function AddressField() {
  return <ThaiAddressAutocomplete onValueChange={(address) => console.log(address)} />
}
```
