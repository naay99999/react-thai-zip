## Try the live component

This is the canonical `ThaiAddressAutocomplete` scaffold from react-thaizip, not a copy built only for these docs. After adding it to your project, you own the generated source and can tailor it freely.

## Quick start

```bash
npx react-thaizip init
npx react-thaizip add autocomplete cascade-select
```

The first command checks Tailwind and creates configuration; the second adds both components and their required shared files.
