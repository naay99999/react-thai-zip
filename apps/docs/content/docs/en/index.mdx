**react-thaizip is not a component library you install as a dependency.** It is a CLI that copies Thai address component source into your project, the same way [shadcn/ui](https://ui.shadcn.com/) does. Once added, the files are your code: change the markup, styles, or behavior directly.

The example above is `ThaiAddressAutocomplete` from the real template the CLI copies, not a copy written for these docs. Open the "Code" tab to see the code it uses.

## Principles

- **You own the code**: components live in your project, so customizing them needs no style overrides or wrappers.
- **Data included**: search subdistricts, districts, provinces, and postal codes in Thai or English with [thaizip](https://naay99999.github.io/thai-zip/en/), without calling an external API.
- **Fits your design system**: get the vanilla style (Base UI + Tailwind) or files composed from your shadcn/ui primitives (Base UI, Radix, or React Aria), whichever `init` detects.
- **AI-ready**: every page has a Markdown version with the example code, plus [`/llms.txt`](/llms.txt) and [`/llms-full.txt`](/llms-full.txt). See [Use react-thaizip with AI](/en/docs/guides/using-with-ai).

## Components

| Component | Use it when |
| --- | --- |
| [Autocomplete](/en/docs/components/autocomplete) | People type to search by subdistrict, district, province, or postal code |
| [Cascade select](/en/docs/components/cascade-select) | People pick province → district → subdistrict in order |
| [Address form](/en/docs/components/address-form) | You need house number, moo, soi, and street plus the address hierarchy in one form |
| [Address display](/en/docs/components/address-display) | You show a saved address read-only |
| [Address form field](/en/docs/components/address-form-field) | You bind the cascade select to react-hook-form |

## Quick start

```bash
npx react-thaizip init
npx react-thaizip add autocomplete
```

`init` checks Tailwind and shadcn/ui and writes `thaizip.config.json`; `add` copies the component with its helper files and installs dependencies. See [Get started](/en/docs/getting-started) for each step.

Need the lower-level address search API to build your own UI? See the [thaizip Core API](https://naay99999.github.io/thai-zip/en/).
