## `formatThaiAddressSuggestion`

```ts
function formatThaiAddressSuggestion(record: ThaiAddressRecord, options?: { locale?: 'th' | 'en' }): ThaiAddressSuggestion
```

Builds a ready-to-render label for a dropdown item.

```ts
const suggestions = searchThaiAddress(index, 'ลาดพร้าว').map((r) => formatThaiAddressSuggestion(r))
suggestions[0].label // 'ลาดพร้าว > เขตลาดพร้าว > กรุงเทพมหานคร 10230'

formatThaiAddressSuggestion(record, { locale: 'en' }).label // 'Lat Phrao > Khet Lat Phrao > Bangkok 10230'
```

```ts
type ThaiAddressSuggestion = {
  id: string // String(record.tambonId)
  label: string // labelTh, or labelEn when locale is 'en'
  labelTh: string
  labelEn: string
  tambon: string
  tambonEn: string
  amphure: string
  amphureEn: string
  province: string
  provinceEn: string
  zipCode: string
}
```

## `resolveThaiAddress`

```ts
function resolveThaiAddress(record: ThaiAddressRecord): ResolvedThaiAddress
```

Builds the address object to store. It carries the same values under two naming conventions, so you can pick the one that fits your schema.

```ts
type ResolvedThaiAddress = {
  // Thai convention
  tambon: string
  tambonEn: string
  amphure: string
  amphureEn: string
  province: string
  provinceEn: string
  zipCode: string
  // English convention, same values
  subdistrict: string
  subdistrictEn: string
  district: string
  districtEn: string
  postalCode: string
}
```

The [React hook](/en/docs/react-hook) returns this value, and the [react-thaizip components](/en/docs/react) use it as theirs.
