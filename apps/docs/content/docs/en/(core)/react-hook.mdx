title: React hook
description: useThaiAddressAutocomplete from thaizip/react — debounced search state for your own autocomplete UI
---

`useThaiAddressAutocomplete` wraps `searchThaiAddress` with a debounce and the query/suggestions state. It ships with `"use client"`, so it works in the Next.js App Router as is. For a finished component instead, see the [autocomplete](/en/docs/react/autocomplete).

```tsx
import { useState } from 'react'
import { useThaiAddressAutocomplete } from 'thaizip/react'
import type { ResolvedThaiAddress, TrigramIndex } from 'thaizip'

function AddressAutocomplete({ index }: { index: TrigramIndex }) {
  const [selected, setSelected] = useState<ResolvedThaiAddress | null>(null)
  const { query, setQuery, setQuerySilent, suggestions, isOpen, selectSuggestion } =
    useThaiAddressAutocomplete({ index, onSelect: setSelected })

  return (
    <div>
      <input value={query} onChange={(e) => setQuery(e.target.value)} />
      {isOpen && (
        <ul>
          {suggestions.map((s) => (
            <li key={s.id} onClick={() => selectSuggestion(s) && setQuerySilent(s.label)}>
              {s.label}
            </li>
          ))}
        </ul>
      )}
    </div>
  )
}
```

`index` must not be null, and hooks can't be called conditionally. If you load the index asynchronously, render this component only once `loadDefaultIndex()` has resolved.

## Options

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `index` | `TrigramIndex` | required | The index to search. |
| `debounce` | `number` | `200` | Milliseconds to wait after typing stops. |
| `limit` | `number` | `10` | Passed to `searchThaiAddress`. |
| `threshold` | `number` | `0.4` | Passed to `searchThaiAddress`. |
| `zipLimit` | `number` | — | Passed to `searchThaiAddress`. |
| `locale` | `'th' \| 'en'` | `'th'` | Language of each suggestion's `label`. |
| `initialQuery` | `string` | `''` | Initial input text. Does not trigger a search. |
| `onSelect` | `(address: ResolvedThaiAddress) => void` | — | Called when `selectSuggestion` resolves an address. |

## Returns

| Value | Description |
| --- | --- |
| `query` | Current input text. |
| `setQuery(value)` | Update the text and search after the debounce. |
| `setQuerySilent(value)` | Update the text without searching or reopening, e.g. to show the selected label. |
| `suggestions` | `ThaiAddressSuggestion[]` from the latest search. |
| `isOpen` | `true` when there is a query and at least one suggestion. |
| `selectSuggestion(item)` | Resolve a suggestion, call `onSelect`, and return the `ResolvedThaiAddress` (or `null` for a stale item). It does not change `query`. |
| `clear()` | Reset `query` and `suggestions`. |
