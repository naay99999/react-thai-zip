`thaizip` is a headless Thai address search library. It bundles the national address dataset, searches it in the browser or on the server, and works with any framework.

| Package | Use it when |
| --- | --- |
| `thaizip` | You want the search API, or you are building your own UI. These pages. |
| [`react-thaizip`](/en/docs/react) | You want ready-made React components (autocomplete, cascade select, address form) copied into your project. |

## Install

```npm
npm install thaizip
```

Node.js 18 or later. React is an optional peer dependency, needed only for `thaizip/react`.

| Import | Contents |
| --- | --- |
| `thaizip` | Core functions and types (4.4 KB gzip) |
| `thaizip/react` | The [`useThaiAddressAutocomplete`](/en/docs/react-hook) hook |
| `thaizip/data` | The bundled dataset loader (2.3 KB gzip, plus a 114 KB gzip data chunk fetched on first load) |

## Quick start

```ts
import { loadDefaultIndex } from 'thaizip/data'
import { searchThaiAddress, resolveThaiAddress } from 'thaizip'

const index = await loadDefaultIndex()

const [record] = searchThaiAddress(index, 'ลาดพร้าว') // also 'bang rak' or '10500'
const address = resolveThaiAddress(record)
// { subdistrict: 'ลาดพร้าว', district: 'เขตลาดพร้าว', province: 'กรุงเทพมหานคร', postalCode: '10230', … }
```

`loadDefaultIndex()` builds the search index once (about 40 ms) and caches it. Call it when the page or route loads, not on the first keystroke.
