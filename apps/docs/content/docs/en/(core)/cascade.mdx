---
title: Cascade lists
description: listProvinces, listAmphures, and listTambons for province → district → sub-district dropdowns
---

These functions list addresses level by level, for dropdowns where people pick a province, then a district, then a sub-district. They read groupings built with the index, so they are cheap to call on every change.

```ts
import { listProvinces, listAmphures, listTambons } from 'thaizip'

const provinces = listProvinces(index)            // all 77
const districts = listAmphures(index, provinceId)
const subdistricts = listTambons(index, amphureId) // each with its zipCode
```

| Function | Returns |
| --- | --- |
| `listProvinces(index)` | `ProvinceSummary[]`, sorted by Thai name |
| `listAmphures(index, provinceId)` | `AmphureSummary[]` in that province, sorted by Thai name |
| `listTambons(index, amphureId)` | `TambonSummary[]` in that district, sorted by Thai name |

```ts
type ProvinceSummary = { id: number; nameTh: string; nameEn: string }
type AmphureSummary = { id: number; nameTh: string; nameEn: string; provinceId: number }
type TambonSummary = { id: number; nameTh: string; nameEn: string; amphureId: number; zipCode: string }
```

An unknown id, such as a `0` placeholder before anything is selected, returns `[]` instead of throwing. When the parent selection changes, reset the child ids and the lists empty themselves.

For a ready-made component built on these functions, see the [cascade select](/en/docs/react/cascade-select).
