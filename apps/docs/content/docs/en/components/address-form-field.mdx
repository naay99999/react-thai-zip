title: react-hook-form address field
description: Wrap the cascade select in react-hook-form's Controller to bind it to an existing form's validation and state
---

`ThaiAddressFormField` is for forms that already use [react-hook-form](https://react-hook-form.com/) and want the address bound directly into form state, instead of reading it from hidden inputs. Its prop shape is deliberately different from the other components: pass `control`/`name`/`rules` the same way you would to react-hook-form's own `useController`, and there is no `value`/`onValueChange`/hidden inputs.

## Usage

```tsx
import { useForm } from 'react-hook-form'
import type { ResolvedThaiAddress } from 'thaizip'
import { ThaiAddressFormField } from '@/components/thai-address-form-field'
```

```tsx
const { control, handleSubmit } = useForm<{ address: ResolvedThaiAddress | null }>({
  defaultValues: { address: null },
})
```

```tsx
<ThaiAddressFormField control={control} name="address" />
```

The `name` you pass (`"address"` above) must have type `ResolvedThaiAddress | null` in the form's value type. react-hook-form's own `handleSubmit` reads the value directly — this component renders no hidden inputs.

## API Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `control` | `Control<TFieldValues>` | — | **Required.** The `control` value from react-hook-form's `useForm()`. |
| `name` | `FieldPath<TFieldValues>` | — | **Required.** The form field's path; its value type must be `ResolvedThaiAddress \| null`. |
| `rules` | `Omit<RegisterOptions<…>, 'valueAsNumber' \| 'valueAsDate' \| 'setValueAs' \| 'disabled'>` | — | Forwarded to react-hook-form's `Controller` for validation. |
| `locale` | `'th' \| 'en'` | `'th'` | Label and option locale for the embedded cascade select. |
| `texts` | `Partial<ThaiAddressCascadeSelectTexts>` | — | Forwarded as the embedded cascade select's own `texts` prop. |
| `indexLoad` | `'mount' \| 'visible'` | `'mount'` | Forwarded to the embedded cascade's address-index loader. |
| `disabled` | `boolean` | — | Disables every select in the embedded cascade select. |
| `className` | `string` | — | The `<div>` wrapping the cascade select and its validation message. |
| `labelClassName` | `string` | — | The cascade select's labels. |
| `triggerClassName` | `string` | — | The cascade select's triggers and postal-code input. |
| `popupClassName` | `string` | — | The cascade select's option popups. |
| `itemClassName` | `string` | — | Each of the cascade select's option items. |
| `errorClassName` | `string` | — | The `role="alert"` validation message shown when validation fails. |

This component accepts no `value`/`onValueChange`/`ref`/`name` (for a hidden input) like the other components do — react-hook-form reads and writes the value through the `control`/`name` you pass instead.
