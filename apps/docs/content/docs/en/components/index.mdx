---
title: All components
description: Every Thai address component the CLI can add to your project
---

Add any component with `npx react-thaizip add <name>`. Every component except the read-only address display ships in the vanilla style plus one style per shadcn/ui base (Base UI, Radix UI, React Aria); pick the style at the top of a component page to preview it.

<Cards>
  <Card title="Autocomplete" href="/en/docs/components/autocomplete">
    Type to search by sub-district, district, province, or postal code.
  </Card>
  <Card title="Cascade select" href="/en/docs/components/cascade-select">
    Pick province → district → sub-district in order.
  </Card>
  <Card title="Address form" href="/en/docs/components/address-form">
    House number, moo, soi, and street plus the address hierarchy in one form.
  </Card>
  <Card title="Address display" href="/en/docs/components/address-display">
    Show a saved address read-only, with no address-index loading.
  </Card>
  <Card title="Address form field" href="/en/docs/components/address-form-field">
    The cascade select bound to react-hook-form's validation and state.
  </Card>
</Cards>
