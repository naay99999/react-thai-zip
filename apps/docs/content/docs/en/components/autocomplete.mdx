`ThaiAddressAutocomplete` is for forms where people can search an address by sub-district, district, province, or postal code.

## Basic usage

Import from the location generated in your project:

```tsx
import { ThaiAddressAutocomplete } from '@/components/thai-address-autocomplete'

export function AddressField() {
  return <ThaiAddressAutocomplete onValueChange={(address) => console.log(address)} />
}
```

`onValueChange` receives `ResolvedThaiAddress | null`. Selecting a suggestion yields a structured address; typing an empty query clears an existing resolved selection with `null`.

## Props

### Value

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `ResolvedThaiAddress \| null` | Controlled value; pass `null` to clear it. |
| `defaultValue` | `ResolvedThaiAddress \| null` | Uncontrolled seed value; also pre-fills the initial search text. |
| `onValueChange` | `(address: ResolvedThaiAddress \| null) => void` | Called when an address is selected or cleared. |

### Search

| Prop | Type | Description |
| --- | --- | --- |
| `limit` | `number` | Maximum suggestions; passed to the core hook. |
| `debounce` | `number` | Search delay in milliseconds; passed to the core hook. |
| `threshold` | `number` | Minimum query length; passed to the core hook. |

### Field

| Prop | Type | Description |
| --- | --- | --- |
| `name` | `string` | Renders four hidden inputs for subdistrict, district, province, and zipcode. |
| `locale` | `'th' \| 'en'` | Text and label locale; defaults to `'th'`. |
| `disabled` | `boolean` | Disables the search input. |
| `required` | `boolean` | Marks the input as required. |
| `aria-invalid` | `React.AriaAttributes['aria-invalid']` | Marks the input as invalid. |
| `onBlur` | `React.FocusEventHandler<HTMLInputElement>` | Runs when the input loses focus. |
| `onError` | `(error: Error) => void` | Runs if the address index cannot load. |

### Text

| Prop | Type | Description |
| --- | --- | --- |
| `texts` | `Partial<ThaiAddressAutocompleteTexts>` | Overrides the placeholder, loading/error/empty states, and clear/retry labels. |

### Class slots

| Prop | Applied to |
| --- | --- |
| `className` | Root wrapper |
| `inputClassName` | Search input |
| `popupClassName` | Results popup |
| `itemClassName` | Each result item |

### Ref

| Prop | Type | Description |
| --- | --- | --- |
| `ref` | `React.Ref<HTMLInputElement>` | Forwarded to the input. |
