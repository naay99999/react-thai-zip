`ThaiAddressForm` is for forms that need a full address: house number/moo/soi/street plus sub-district, district, and province. It embeds a [cascade select](/en/docs/components/cascade-select) internally.

<ComponentPreview name="address-form-en" lang="en" size="lg" />

## Installation

<ComponentInstall name="address-form" lang="en" />

## Usage

```tsx
import { ThaiAddressForm } from '@/components/thai-address-form'
```

```tsx
<ThaiAddressForm onValueChange={(address) => console.log(address)} />
```

`onValueChange` receives `FullThaiAddress | null`. It is only non-null once the house number is filled in and all three cascade levels are selected.

## Examples

### Thai input

Without `locale`, labels and options are in Thai (the default `locale="th"`), for both the free-text fields and the embedded cascade select.

<ComponentPreview name="address-form-demo" lang="en" size="lg" />

### Controlled

Pass `value` to control the whole address, or `defaultValue` to seed it. An in-progress, not-yet-complete cascade selection is never cleared, even while the controlled `value` is `null`.

<ComponentPreview name="address-form-controlled-en" lang="en" size="lg" />

### Disabled

Pass `disabled` to disable every text field and select.

<ComponentPreview name="address-form-disabled" lang="en" size="lg" />

### Invalid

Pass `aria-invalid` to mark the four text inputs and the cascade's triggers invalid.

<ComponentPreview name="address-form-invalid" lang="en" size="lg" />

### Custom text

Use `texts` for this component's own labels and placeholders, and `cascadeTexts` for the embedded cascade select's.

<ComponentPreview name="address-form-texts-en" lang="en" size="lg" />

### Form

A complete checkout-style form: recipient and phone fields next to the address, with Cancel and Submit buttons. Passing `name` renders eight hidden inputs, so a plain `FormData` holds the whole address. See [Forms](/en/docs/guides/forms) for more patterns.

## API Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `FullThaiAddress \| null` | — | Controlled value; pass `null` to clear it. |
| `defaultValue` | `FullThaiAddress \| null` | — | Uncontrolled seed value; pre-fills both the text fields and the embedded cascade. |
| `onValueChange` | `(address: FullThaiAddress \| null) => void` | — | Called once the house number is non-blank and all three levels are selected, or when the value becomes incomplete again. |
| `name` | `string` | — | Renders 8 hidden inputs: the cascade's own 4 (`-subdistrict`/`-district`/`-province`/`-zipcode`) plus this component's own 4 (`-houseno`/`-moo`/`-soi`/`-street`). |
| `locale` | `'th' \| 'en'` | `'th'` | Text and label locale for both this component and the embedded cascade. |
| `texts` | `Partial<ThaiAddressFormTexts>` | — | Overrides the house-number/moo/soi/street labels and placeholders. |
| `cascadeTexts` | `Partial<ThaiAddressCascadeSelectTexts>` | — | Forwarded as the embedded cascade select's own `texts` prop. |
| `indexLoad` | `'mount' \| 'visible'` | `'mount'` | Forwarded to the embedded cascade's address-index loader. |
| `disabled` | `boolean` | `false` | Disables every text field and the embedded cascade. |
| `required` | `boolean` | `false` | Marks the house-number field and the embedded cascade as required (moo/soi/street stay optional). |
| `aria-invalid` | `React.AriaAttributes['aria-invalid']` | — | Marks the four text inputs and the cascade's triggers invalid. |
| `onBlur` | `React.FocusEventHandler<HTMLInputElement>` | — | Runs only when the house-number input loses focus. |
| `onError` | `(error: Error) => void` | — | Runs if the address index cannot load (handled by the embedded cascade). |
| `className` | `string` | — | Root wrapper. |
| `labelClassName` | `string` | — | Labels of the text fields and the cascade. |
| `inputClassName` | `string` | — | The house-number/moo/soi/street inputs. |
| `triggerClassName` | `string` | — | The cascade's select triggers and postal-code input. |
| `popupClassName` | `string` | — | The cascade's option popups. |
| `itemClassName` | `string` | — | Each of the cascade's option items. |
| `ref` | `React.Ref<HTMLInputElement>` | — | Forwarded to the house-number input. |
