`ThaiAddressFormField` เหมาะกับฟอร์มที่ใช้ [react-hook-form](https://react-hook-form.com/) อยู่แล้วและต้องการผูกที่อยู่เข้ากับ state ของฟอร์มโดยตรง แทนที่จะอ่านค่าจาก hidden inputs รูปแบบ prop ต่างจากคอมโพเนนต์อื่นโดยตั้งใจ: ส่ง `control`/`name`/`rules` เหมือนกับ `useController` ของ react-hook-form เอง และไม่มี `value`/`onValueChange`/hidden inputs

## วิธีใช้

```tsx
import { useForm } from 'react-hook-form'
import type { ResolvedThaiAddress } from 'thaizip'
import { ThaiAddressFormField } from '@/components/thai-address-form-field'
```

```tsx
const { control, handleSubmit } = useForm<{ address: ResolvedThaiAddress | null }>({
  defaultValues: { address: null },
})
```

```tsx
<ThaiAddressFormField control={control} name="address" />
```

ฟิลด์ `name` ที่ระบุ (`"address"` ในตัวอย่าง) ต้องมีชนิดค่าเป็น `ResolvedThaiAddress | null` ใน type ของฟอร์ม `handleSubmit` ของ react-hook-form อ่านค่าได้โดยตรง คอมโพเนนต์นี้ไม่ render hidden inputs

## ตัวอย่าง

### กรอกข้อมูลภาษาอังกฤษ

ใช้ `locale="en"` เพื่อแสดงป้ายและตัวเลือกของ cascade select ที่ฝังอยู่เป็นภาษาอังกฤษ

<ComponentPreview name="address-form-field-en" size="lg" />

### ตรวจสอบด้วย validation rule

ส่ง `rules` แบบเดียวกับที่ส่งให้ `Controller`/`useController` ของ react-hook-form ตัวอย่างนี้กำหนดให้ต้องเลือกที่อยู่ครบก่อนส่งฟอร์ม ข้อความ error จะแสดงเป็น `<p role="alert">` ใต้ cascade select

<ComponentPreview name="address-form-field-validation" size="lg" />

### ปิดใช้งาน

ส่ง `disabled` เพื่อปิดทุก select ใน cascade select ที่ฝังอยู่

<ComponentPreview name="address-form-field-disabled" size="lg" />

### ใช้ในฟอร์ม

ฟิลด์ที่อยู่คู่กับ input ทั่วไปที่ใช้ `register` ในฟอร์มเดียวกัน ทั้งสองช่องตรวจสอบตอนส่ง และ `handleSubmit` ได้ค่าทั้งหมดพร้อมกัน

## API Reference

| Prop | Type | ค่าเริ่มต้น | รายละเอียด |
| --- | --- | --- | --- |
| `control` | `Control<TFieldValues>` | — | **จำเป็น** ค่า `control` จาก `useForm()` ของ react-hook-form |
| `name` | `FieldPath<TFieldValues>` | — | **จำเป็น** path ของฟิลด์ในฟอร์ม ชนิดค่าต้องเป็น `ResolvedThaiAddress \| null` |
| `rules` | `Omit<RegisterOptions<…>, 'valueAsNumber' \| 'valueAsDate' \| 'setValueAs' \| 'disabled'>` | — | ส่งต่อไปยัง `Controller` ของ react-hook-form เพื่อตรวจสอบค่า |
| `locale` | `'th' \| 'en'` | `'th'` | ภาษาของป้ายและตัวเลือกใน cascade select ที่ฝังอยู่ |
| `texts` | `Partial<ThaiAddressCascadeSelectTexts>` | — | ส่งต่อเป็น `texts` ของ cascade select ที่ฝังอยู่ |
| `indexLoad` | `'mount' \| 'visible'` | `'mount'` | ส่งต่อไปยังตัวโหลดดัชนีที่อยู่ของ cascade ที่ฝังอยู่ |
| `disabled` | `boolean` | — | ปิดใช้งานทุก select ใน cascade select ที่ฝังอยู่ |
| `className` | `string` | — | `<div>` ที่ครอบ cascade select และข้อความ validation |
| `labelClassName` | `string` | — | ป้ายกำกับของ cascade select |
| `triggerClassName` | `string` | — | trigger และช่องรหัสไปรษณีย์ของ cascade select |
| `popupClassName` | `string` | — | กล่องตัวเลือกของ cascade select |
| `itemClassName` | `string` | — | แต่ละตัวเลือกของ cascade select |
| `errorClassName` | `string` | — | ข้อความ validation `role="alert"` ที่แสดงเมื่อตรวจสอบไม่ผ่าน |

คอมโพเนนต์นี้ไม่รับ `value`/`onValueChange`/`ref`/`name` (สำหรับ hidden input) แบบคอมโพเนนต์อื่น react-hook-form อ่านและเขียนค่าผ่าน `control`/`name` ที่ส่งให้แทน
