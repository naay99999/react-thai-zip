---
title: คอมโพเนนต์ทั้งหมด
description: คอมโพเนนต์ที่อยู่ไทยทั้งหมดที่ CLI เพิ่มลงโปรเจกต์ได้
---

เพิ่มคอมโพเนนต์ใดก็ได้ด้วย `npx react-thaizip add <name>` ทุกตัวยกเว้นตัวแสดงที่อยู่แบบอ่านอย่างเดียวมี style แบบ vanilla และอีกหนึ่ง style ต่อ base ของ shadcn/ui (Base UI, Radix UI, React Aria) เลือก style ได้ที่ด้านบนของหน้าคอมโพเนนต์เพื่อดูตัวอย่าง

<Cards>
  <Card title="Autocomplete" href="/docs/components/autocomplete">
    พิมพ์ค้นหาด้วยตำบล อำเภอ/เขต จังหวัด หรือรหัสไปรษณีย์
  </Card>
  <Card title="Cascade select" href="/docs/components/cascade-select">
    เลือกจังหวัด → อำเภอ/เขต → ตำบล/แขวง ตามลำดับ
  </Card>
  <Card title="ฟอร์มที่อยู่แบบเต็ม" href="/docs/components/address-form">
    บ้านเลขที่ หมู่ ซอย ถนน พร้อมเลือกที่อยู่ตามลำดับชั้นในฟอร์มเดียว
  </Card>
  <Card title="แสดงที่อยู่" href="/docs/components/address-display">
    แสดงที่อยู่ที่บันทึกไว้แบบอ่านอย่างเดียว ไม่ต้องโหลดดัชนีที่อยู่
  </Card>
  <Card title="ฟิลด์ react-hook-form" href="/docs/components/address-form-field">
    cascade select ที่ผูกกับ validation และ state ของ react-hook-form
  </Card>
