`ThaiAddressForm` เหมาะกับฟอร์มที่ต้องการที่อยู่แบบเต็ม คือบ้านเลขที่/หมู่/ซอย/ถนน บวกกับตำบล อำเภอ/เขต และจังหวัด โดยฝัง [cascade select](/docs/components/cascade-select) ไว้ภายในให้แล้ว

<ComponentPreview name="address-form-demo" size="lg" />

## ติดตั้ง

<ComponentInstall name="address-form" />

## วิธีใช้

```tsx
import { ThaiAddressForm } from '@/components/thai-address-form'
```

```tsx
<ThaiAddressForm onValueChange={(address) => console.log(address)} />
```

ค่าใน `onValueChange` คือ `FullThaiAddress | null` จะไม่เป็น `null` ก็ต่อเมื่อกรอกบ้านเลขที่แล้วและเลือกที่อยู่ตามลำดับชั้นครบทั้งสามระดับ

## ตัวอย่าง

### กรอกข้อมูลภาษาอังกฤษ

ใช้ `locale="en"` เพื่อแสดงป้ายกำกับและตัวเลือกเป็นภาษาอังกฤษ ทั้งฟิลด์ข้อความของตัวเองและ cascade select ที่ฝังอยู่

<ComponentPreview name="address-form-en" size="lg" />

### ควบคุมค่าจากภายนอก

ส่ง `value` เพื่อควบคุมค่าทั้งชุด หรือ `defaultValue` เพื่อตั้งค่าเริ่มต้น การเลือกที่อยู่ตามลำดับชั้นที่ยังเลือกไม่ครบจะไม่ถูกล้าง แม้ `value` ที่ควบคุมอยู่จะเป็น `null`

<ComponentPreview name="address-form-controlled" size="lg" />

### ปิดใช้งาน

ส่ง `disabled` เพื่อปิดทุกช่องกรอกและทุก select

<ComponentPreview name="address-form-disabled" size="lg" />

### ไม่ผ่านการตรวจสอบ

ส่ง `aria-invalid` เพื่อทำเครื่องหมายว่าช่องกรอกทั้งสี่และ trigger ของ cascade ไม่ผ่านการตรวจสอบ

<ComponentPreview name="address-form-invalid" size="lg" />

### ปรับข้อความ

ใช้ `texts` สำหรับป้ายกำกับและ placeholder ของคอมโพเนนต์นี้ และ `cascadeTexts` สำหรับ cascade select ที่ฝังอยู่

<ComponentPreview name="address-form-texts" size="lg" />

### ใช้ในฟอร์ม

ฟอร์มแบบหน้าชำระเงิน: มีช่องชื่อผู้รับและเบอร์โทรคู่กับที่อยู่ พร้อมปุ่มยกเลิกและบันทึก การส่ง `name` จะสร้าง hidden inputs แปดช่อง `FormData` ธรรมดาจึงได้ที่อยู่ครบทั้งชุด ดูรูปแบบอื่นได้ที่ [การใช้งานร่วมกับฟอร์ม](/docs/guides/forms)

<ComponentPreview name="address-form-submit" size="lg" />

## API Reference

| Prop | Type | ค่าเริ่มต้น | รายละเอียด |
| --- | --- | --- | --- |
| `value` | `FullThaiAddress \| null` | — | ค่าที่ควบคุมอยู่; ส่ง `null` เพื่อล้าง |
| `defaultValue` | `FullThaiAddress \| null` | — | ค่าเริ่มต้นของโหมด uncontrolled เติมทั้งช่องข้อความและ cascade ที่ฝังอยู่ |
| `onValueChange` | `(address: FullThaiAddress \| null) => void` | — | เรียกเมื่อบ้านเลขที่ไม่ว่างและเลือกครบทั้งสามระดับ หรือเมื่อค่ากลับมาไม่ครบอีกครั้ง |
| `name` | `string` | — | สร้าง hidden inputs 8 ช่อง: 4 ช่องของ cascade (`-subdistrict`/`-district`/`-province`/`-zipcode`) และ 4 ช่องของคอมโพเนนต์นี้ (`-houseno`/`-moo`/`-soi`/`-street`) |
| `locale` | `'th' \| 'en'` | `'th'` | ภาษาของข้อความและป้ายกำกับ ทั้งของคอมโพเนนต์นี้และ cascade ที่ฝังอยู่ |
| `texts` | `Partial<ThaiAddressFormTexts>` | — | แทนที่ป้ายกำกับและ placeholder ของบ้านเลขที่/หมู่/ซอย/ถนน |
| `cascadeTexts` | `Partial<ThaiAddressCascadeSelectTexts>` | — | ส่งต่อเป็น `texts` ของ cascade select ที่ฝังอยู่ |
| `indexLoad` | `'mount' \| 'visible'` | `'mount'` | ส่งต่อไปยังตัวโหลดดัชนีที่อยู่ของ cascade ที่ฝังอยู่ |
| `disabled` | `boolean` | `false` | ปิดใช้งานทุกช่องข้อความและ cascade ที่ฝังอยู่ |
| `required` | `boolean` | `false` | กำหนดให้ช่องบ้านเลขที่และ cascade ต้องมีค่า (หมู่/ซอย/ถนนยังไม่บังคับ) |
| `aria-invalid` | `React.AriaAttributes['aria-invalid']` | — | ทำเครื่องหมายว่าช่องข้อความทั้งสี่และ trigger ของ cascade ไม่ผ่านการตรวจสอบ |
| `onBlur` | `React.FocusEventHandler<HTMLInputElement>` | — | ทำงานเฉพาะเมื่อช่องบ้านเลขที่สูญเสียโฟกัส |
| `onError` | `(error: Error) => void` | — | ทำงานเมื่อโหลดดัชนีที่อยู่ไม่สำเร็จ (จัดการโดย cascade ที่ฝังอยู่) |
| `className` | `string` | — | wrapper หลัก |
| `labelClassName` | `string` | — | ป้ายกำกับของช่องข้อความและ cascade |
| `inputClassName` | `string` | — | ช่องบ้านเลขที่/หมู่/ซอย/ถนน |
| `triggerClassName` | `string` | — | trigger ของ select และช่องรหัสไปรษณีย์ใน cascade |
| `popupClassName` | `string` | — | กล่องตัวเลือกของ cascade |
| `itemClassName` | `string` | — | แต่ละตัวเลือกของ cascade |
| `ref` | `React.Ref<HTMLInputElement>` | — | ส่งต่อไปยังช่องบ้านเลขที่ |
